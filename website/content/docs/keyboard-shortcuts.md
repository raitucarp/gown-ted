Boost your productivity and stay in the flow using these keyboard shortcuts:

## File & Workspace Shortcuts

| Action | Windows / Linux | macOS |
|---|---|---|
| **New Document** | `Ctrl + N` | `Cmd + N` |
| **Open File** | `Ctrl + O` | `Cmd + O` |
| **Save Document** | `Ctrl + S` | `Cmd + S` |
| **Close Tab** | `Ctrl + W` | `Cmd + W` |
| **Toggle Focus Mode** | `Ctrl + Shift + F` | `Cmd + Shift + F` |

---

## Editor Formatting Shortcuts

| Action | Shortcut |
|---|---|
| **Bold** | `Ctrl + B` (`Cmd + B`) |
| **Italic** | `Ctrl + I` (`Cmd + I`) |
| **Underline** | `Ctrl + U` (`Cmd + U`) |
| **Strikethrough** | `Ctrl + Shift + X` (`Cmd + Shift + X`) |
| **Inline Code** | `Ctrl + E` (`Cmd + E`) |
| **Heading 1 / 2 / 3** | `Ctrl + Alt + 1 / 2 / 3` |
| **Bullet List** | `Ctrl + Shift + 8` |
| **Numbered List** | `Ctrl + Shift + 7` |
| **Blockquote** | `Ctrl + Shift + B` |
| **Undo / Redo** | `Ctrl + Z` / `Ctrl + Y` (`Cmd + Shift + Z`) |

## WordNet & Autocomplete Shortcuts

| Action | Shortcut |
|---|---|
| **Trigger Autocomplete** | Type at least 2 characters (automatic debounce) |
| **Navigate Suggestions** | `↑` Up Arrow / `↓` Down Arrow |
| **Accept Suggestion** | `Enter` or `Tab` |
| **Dismiss Suggestions** | `Escape` |
| **Inspect Word Under Cursor** | Double-click word or move cursor within word |
